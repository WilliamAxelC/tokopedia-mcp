INTEGRATION

Client Setup (Claude & Cursor)

Connect Claude Desktop or Cursor directly to the official MCP tools via npm.

⚙️ claude_desktop_config.json 
{
  "mcpServers": {
    "shopee-indonesia": {
      "command": "npx",
      "args": ["-y", "shopee-indonesia-mcp", "--stdio"]
    },
    "tokopedia": {
      "command": "npx",
      "args": ["-y", "tokopedia-mcp", "--stdio"]
    },
    "facebook-marketplace": {
      "command": "npx",
      "args": ["-y", "facebook-marketplace-mcp", "--stdio"]
    },
    "coursera": {
      "command": "npx",
      "args": ["-y", "coursera-mcp-server", "--stdio"]
    }
  }
}

📦 Standard npm execution: Claude Desktop and Cursor execute the packages directly via npx with standard input/output (stdio) transports for fast, local-speed tool execution.

INFRASTRUCTURE

Gateway Architecture

Multi-tenant orchestration running in Proxmox LXC with Cloudflare Zero Trust tunnel protection.

🌐 Edge Tunnel & SSL

All inbound traffic on mcp.cuang.dev is routed through Cloudflare's edge network via an encrypted tunnel directly into the Docker bridge network.

⚖️ Nginx Reverse Proxy

A unified Nginx container exposes HTTP/1.1 chunked streaming and Server-Sent Events (SSE) buffering disabled for real-time model communication.

🛡️ Rate Limiting & Security

In-memory sliding window rate limiting and optional API key authentication guarantee high availability across microservices.
